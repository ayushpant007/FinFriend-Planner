---
name: Cross-category fund report design
description: Shared fund-details section styling across Full Planner and SIF/PMS/AIF reports.
---

Use the Full Planner's fund-table presentation as the visual reference for fund-related sections in SIF, PMS, and AIF reports. Populate those sections from the selected product's own available data; do not fabricate Full Planner allocations, return periods, or other unavailable fields.

**Why:** The user wants consistent report styling across product categories, while each category has different source data and some sources omit performance or allocation details.

**How to apply:** Keep the in-app report and its downloaded PDF aligned. Show actual SIF/PMS performance data when present, AIF registry details when that's the available source, and label missing values as unavailable rather than filling them with assumptions.
