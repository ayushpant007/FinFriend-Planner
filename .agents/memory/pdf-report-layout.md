---
name: PDF report layout expectations
description: User-facing requirements for downloaded Planner and investment report PDFs.
---

Downloaded report PDFs should have consistent margins, no clipped text or data, and clean section boundaries. Keep section titles with the table or content they introduce, split long tables between complete rows, repeat column headers on continuation pages, and avoid repeating product names or report titles unnecessarily.

Use the investor's entered name followed by “Investment Proposal” as the visible title and PDF document title across report types.

**Why:** These are client-facing planning reports; clipped or ambiguous pagination makes the information harder to use and can undermine confidence in the plan.

**How to apply:** Verify the actual downloaded PDFs page by page for each report path; do not assume a clean in-app report screen guarantees a clean PDF. Keep screen layout changes separate unless the user also asks for them.
